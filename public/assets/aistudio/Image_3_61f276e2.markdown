## Brand & Style

This design system establishes a high-precision, minimal admin dashboard tailored for cybersecurity and digital image forensics. The personality is strictly professional, analytical, and uncompromisingly clear, drawing from a **Minimalism** and **Corporate/Modern** movement blend. 

The interface evokes an emotional response of absolute trust, deep focus, and rigorous methodology. Every visual element is stripped of decorative friction to ensure investigators can parse complex metadata, cryptographic hashes, and visual anomalies without distraction. High data density is managed through clean architectural discipline, deliberate whitespace, and structured low-contrast borders.

## Colors

The palette is engineered for prolonged analytical sessions under high-scrutiny environments. The foundation is a crisp, clinical white canvas backed by very light neutral gray-blues. Deep navy provides uncompromising legibility for primary text and analytical readouts, while a focused electric blue drives active states and interactive elements. 

- **Primary (`#2563EB`):** Precision accent used for actionable states, active navigation items, and critical data highlights.
- **Secondary (`#0F172A`):** Deep navy anchoring structural typography, headers, and dense data labels.
- **Tertiary (`#64748B`):** Muted slate for secondary metadata, inactive borders, and supporting telemetry.
- **Neutral (`#F8FAFC`):** Clean operational canvas and surface layering.

## Typography

The typographic hierarchy pairs a highly legible, neutral grotesque sans-serif for UI chrome and narratives with a precise monospace face for technical telemetry, hex codes, cryptographic hashes, and coordinate data. 

- **Inter** is utilized for all interface copy, delivering immaculate scaling and neutral legibility across dense dashboard widgets.
- **JetBrains Mono** is reserved exclusively for structured data points, timestamps, checksums, and forensic metadata indicators to ensure effortless column alignment and rapid scanning.

## Layout & Spacing

The layout is governed by a strict **12-column fluid grid** system optimized for high-resolution desktop investigator stations, gracefully scaling down to structured tablet and mobile viewports. 

- **Gutters & Margins:** Standardized at 16px (`1rem`) gutters and 24px (`1.5rem`) outer margins to maximize screen real estate for image canvas viewports and deep inspection panels.
- **Spacing Rhythm:** Built on an 4px/8px modular scale. Component padding and element grouping rely strictly on predictable increments (`space-xs` through `space-xl`) to maintain rhythmic vertical alignment across complex multi-pane analytical dashboards.

## Elevation & Depth

Depth is conveyed through **low-contrast outlines** and clean surface-container tiers rather than heavy, distracting drop shadows. 

- **Surface Layering:** The application canvas sits at the base level, with analytical cards and panels elevated via crisp 1px borders (`#E2E8F0`) and subtle background tonal shifts (`#FFFFFF` on `#F8FAFC`).
- **Focus States:** Active inspection windows and modal overlays utilize minimal, high-precision structural boundaries with an electric blue focus ring, preserving the flat, utilitarian ethos required for professional forensic tools.

## Shapes

The shape language employs a **Soft** roundedness level (`0.25rem` base border radius), providing just enough softening to prevent visual fatigue without sacrificing the authoritative, engineering-grade aesthetic. 

- **Containers & Inputs:** Standard elements use tight corners (`4px`) to align with dense tabular data layouts and pixel-precise image grids.
- **Badges & Indicators:** Pill shapes are reserved exclusively for status indicators, threat level tags, and forensic classification chips.

## Components

All components are engineered for maximum operational efficiency, predictable states, and zero visual noise.

- **Buttons:** Rendered with crisp boundaries. Primary actions use solid electric blue (`#2563EB`) with white text; secondary actions use transparent backgrounds with dark navy borders and text. Hover and active states exhibit immediate tonal shifts without animated friction.
- **Chips & Tags:** Compact, monospace-driven indicators used for file types, EXIF status flags, and algorithmic confidence scores. 
- **Lists & Tables:** Dense, high-density data tables featuring alternating row hints, sticky headers, and monospace alignment for numeric metrics, hashes, and byte offsets.
- **Checkboxes & Radio Buttons:** Clean square and circular selectors with sharp 1px borders, utilizing clear filled check states in primary accent color.
- **Input Fields:** Outlined text boxes with embedded monospace support for query filters, file path inputs, and hex search parameters. Includes clear focus indicators and inline validation feedback.
- **Cards:** White surface containers bounded by crisp 1px neutral borders, organizing discrete analytical modules such as image histograms, noise analysis readouts, and metadata trees.
- **Specialized Components:** Includes side-by-side image comparison viewports, magnification loupes, Error Level Analysis (ELA) toggle bars, and cryptographic hash verification banners.
